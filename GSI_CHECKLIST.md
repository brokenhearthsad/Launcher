# Чек-лист ручной проверки GSI на Windows (настоящая Dota 2)

Цель: убедиться, что Launcher получает реальные данные Dota 2 Game State Integration в режиме
только чтения и не мешает игре. Отмечайте пункты по порядку. Рейтинговые матчи для проверки
не нужны — достаточно «Демонстрации героя» или матча с ботами.

## A. Подготовка
- [ ] `stop.bat`, скачать ветку `claude/dota-match-lab` заново, `install.bat` → «Installation complete».
- [ ] В `backend\data\backups\` появилась копия `match_lab-…-pre-0004.db`.
- [ ] `start.bat` → открылся http://localhost:8000, разделы Phase 1–2 работают как раньше.

## B. Установка конфигурации
- [ ] «Состояние игры» → блок «Конфигурация GSI»: правильный путь к `…\dota 2 beta\game\dota\cfg\gamestate_integration\gamestate_integration_launcher.cfg`.
- [ ] «Другие GSI-файлы» перечисляет ваши существующие конфиги (если есть) с пометкой «не изменяются».
- [ ] «Установить GSI» → окно предпросмотра: «Сейчас / После установки», токен показан частично (`••••••••xxxx`).
- [ ] Кнопка «Подтвердить и установить» неактивна, пока не отмечена галочка подтверждения.
- [ ] После подтверждения: «установлена и актуальна»; файл появился в папке Dota 2; открыв его в Блокноте, видно `uri "http://127.0.0.1:8000/gsi"`.
- [ ] Если файл с таким именем уже был — в «Резервные копии» есть копия `…before_install.cfg`.
- [ ] Логи (страница «Логи» и `backend\logs\app.jsonl`) **не содержат** токен из файла.

## C. Параметр запуска
- [ ] Steam → Библиотека → Dota 2 → Свойства → Параметры запуска: добавить `-gamestateintegration`.
- [ ] «Проверить конфигурацию» → «Параметр запуска: -gamestateintegration найден».
      (Если пишет «Нет данных», Steam хранит настройки в другом профиле — проверьте вручную.)

## D. Реальные данные
- [ ] Запустить Dota 2 **после** установки конфигурации (игра читает её при старте).
- [ ] В главном меню через ≤ 30 с: «Подключение GSI: Данные поступают», журнал «GSI подключился».
      Блок «Игра»: «Игрок не в матче (главное меню)» — это нормально, карта не передаётся.
- [ ] Начать «Демонстрацию героя» или матч с ботами:
  - [ ] журнал: «Получено первое состояние игры», «Фаза: …», «Началась игра»;
  - [ ] «Игра»: фаза, игровое время идёт, счёт команд (если показан в режиме);
  - [ ] «Герой»: имя, уровень, здоровье/мана меняются при получении урона и касте;
  - [ ] «Способности» и «Предметы»: соответствуют игре; купленный предмет появляется ≤ 1–2 с.
- [ ] Обзор: карточка «Состояние игры (GSI)» показывает фазу, время, героя, счёт.
- [ ] Отсутствующие в режиме поля показаны как «Нет данных», а не нули.
- [ ] Выйти из матча → журнал «Игра завершилась…»; в «Матчи (по данным GSI)» одна строка на матч.
- [ ] Закрыть Dota 2 → примерно через 40 с статус «Нет данных (GSI молчит)», журнал «GSI перестал передавать данные».

## E. Нагрузка и невмешательство
- [ ] Во время матча Диспетчер задач: `python.exe` Launcher — ЦП ≈ 0–1 %, память < 150 МБ; `node.exe` от Launcher нет.
- [ ] FPS и отклик Dota 2 без изменений с открытой и закрытой панелью Launcher.
- [ ] Launcher не запускал, не закрывал Dota 2/Steam и не менял их приоритет (Диспетчер задач → Подробности → Приоритет «Обычный»).

## F. Удаление и восстановление
- [ ] «Удалить конфигурацию Launcher» → подтверждение → файл исчез из папки Dota 2, появилась копия `…before_uninstall.cfg`.
- [ ] «Восстановить» у этой копии → подтверждение → файл вернулся (а текущий был сохранён как `…before_restore.cfg`).
- [ ] Ваши другие `gamestate_integration_*.cfg` не изменились (даты изменения прежние).

Результат: пришлите отметки и скриншоты раздела «Состояние игры» во время матча и после выхода из него.
